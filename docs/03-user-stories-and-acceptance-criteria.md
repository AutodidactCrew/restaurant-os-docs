# User Stories & Acceptance Criteria

This file contains the testable backlog mapped to features. It is the canonical source for acceptance criteria used by QA and Product.

Examples (P1):
- US-101 Guest QR order: Menu loads <2s on 3G; cart supports modifiers; order appears in KDS <3s.
- US-201 Tokenized payment: PaymentIntent created, webhook dedup, no duplicate charges.
- US-401 KDS: WS events delivered <3s; item-level status transitions reflected to customers.

All stories are mapped to API endpoints and DB tables. See docs/final-user-stories.md for full list and tests.
