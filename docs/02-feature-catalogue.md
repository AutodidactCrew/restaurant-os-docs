# Feature Catalogue

Canonical feature definitions, release priority, boundaries and dependencies.

Features (priority 1 = MVP):
- Ordering (QR/web, guest & registered flows)
- Checkout & Payments (tokenized payment, refunds)
- Menu Management (catalog + overrides, modifiers, combos)
- Kitchen Operations / KDS (station routing, prep timers)
- Device Integration & Printing (DeviceAgent, print idempotency)
- Tenant & Admin (onboarding, RBAC, audit logs)
- API & Events (idempotency, webhook dedupe, event bus)

Priority 2 (Growth): Inventory, Delivery, Loyalty, Reporting enhancements
Priority 3 (Enterprise): Schema-per-tenant, SSO, franchise workflows

Each feature includes owner, data/API touchpoints, and acceptance criteria in the canonical final-features.md
